# 8bp — PoolPilot Android Shot Lab

Android-only manual billiards shot aiming overlay prototype (no root, no Windows, no VPN).

This repository is being populated with a native Android app and GitHub Actions APK build workflow. The app does not automatically play, read live game state, or guarantee shot accuracy.

Build: GitHub **Actions → Build Android APK → Run workflow**; download artifact `PoolPilot-overlay-debug-apk` and extract `app-debug.apk`.
